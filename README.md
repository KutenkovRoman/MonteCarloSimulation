# Модель для расчета инвентаря контейнеров с помощью симуляции Монте-Карло

## Как устроена модель

у нас есть 5 точек `S` (Дудинка), `A` (Мурманск), `B` (Архангельск), `P` (Санкт-Петербург) и `D` (Китай). В каждой точке есть переменные, которые отвечают за число груженных и пустых контейнеров в этой точке. Есть также суда, которые ходят по 5 маршрутам: Дудинка-Мурманск, Дудинка-Архангельск, Мурманск-Китай, СПб-Китай и Дудинка-Китай (через СМП). Эти суда имеют состояния (например, 'в пути из Дудинки в Мурманск') и изменяют переменные среды (количетсво груженных/порожних контейнеров в каждой точке). Кроме того есть объекты, которые отвеают за трансопртировку: с завода в порт в Дудинке, из Архангельска в СПб, из порта Китая сначала в место разгрузки, а потом в депо

## Таблица с результатами (неактуальная)

Ниже таблица с разными конфигурациями, для каждой было сделано 10000 симуляций:
- столбец `n_containers` показывает сколько было пустых контейнеров изначально в точке `S` (Дудинка)
- столбец `n_main_A` показывает сколько было использовано магистральных судов для пути `A` (через Мурманск)
- столбец `n_main_B` показывает сколько было использовано магистральных судов для пути `B` (через Архангельск)
- столбец `n_feeder_A` показывает сколько было использовано фидерных судов для пути `A`. Здесь `n+m` означает, что сначала использовалось `n` судов, а после навигационной паузы, когда накопилось контейнеров, подключили дополнительные `m` судов. Глобально тут два сценария: когда `m=0` (тогда для пути `B` используется изначально `4` фидерных суда) и когда `m>0` (тогда для пути `B` используется изначально `2` судна, а после паузы еще дополнительные `2`)
- столбец `n_feeder_B` показывает сколько было использовано фидерных судов для пути `B`. Обозначения такие же, как и у предыдущего столбца
- столбец `failure_rate` показывает долю случаев, когда в Дудинке заканчивались свободные контейнеры для производства. В этом случае симуляция останавливалась, возможно, из-за этого значения в следующем столбце чуть-чуть занижены
- столбец `avg_delivered` показывает сколько в среднем по **всем** симуляциям было доставлено контейнеров в Китай за период 365 + 60 дней
- столбец `n_estimated_95%` показывает какого бы числа контейнеров хватило в 95% симуляций для этой конфигурации (в каждой симуляции отсоеживается наименьшее число пустых контейнеров в Дудинке в начале каждого дня и это буквально `n_containers` минус 5% перцентиль по этому числу)
- столбец `S2I` показывает часть контейнеров, которую нужно загрузить на фидерное судно перед его отправкой на участке Дудинка-Мурманск/Архангельск (если, например, это значение равно `0.8`, то нужно чтобы в Дудинке было хотя бы `0.8 * 660 = 528` контейнеров, чтобы отправить фидер)
- столбец `I2D` показывает часть контейнеров, которую нужно загрузить на магистральное судно перед его отправкой на участке Мурманск/СПб-Китай
